---
title: "Eventos de Cartão"
description: "Payloads dos eventos relacionados a cartões salvos — cadastro, tokenização, atualização, remoção e expiração."
icon: "credit-card"
---

Todos os eventos de cartão entregam o mesmo objeto `data` — a representação segura do cartão. O número completo (PAN) e o CVV **nunca** são enviados.

| Campo                 | Tipo    | Descrição                                                        |
|-----------------------|---------|------------------------------------------------------------------|
| `id`                  | string  | UUID do cartão                                                   |
| `card_token`          | string  | Token opaco do cartão — enviado em `payment.card.card_token` ao cobrar |
| `first_six_digits`    | string  | Seis primeiros dígitos (BIN)                                     |
| `last_four_digits`    | string  | Quatro últimos dígitos                                           |
| `brand`               | string  | Bandeira do cartão                                               |
| `holder_name`         | string  | Nome do portador                                                 |
| `exp_month`           | integer | Mês de validade (1–12)                                           |
| `exp_year`            | integer | Ano de validade (YYYY)                                           |
| `type`                | string  | Tipo do cartão (`credit`, `debit`)                               |
| `status`              | string  | Situação do cartão (`active`, `deleted`)                         |
| `tokenization_status` | string  | Situação da tokenização (`pending`, `tokenized`, `failed`)       |
| `created_at`          | string  | Data de criação (ISO 8601)                                       |
| `updated_at`          | string  | Data da última atualização (ISO 8601)                            |
| `deleted_at`          | string  | Data de exclusão (ISO 8601) — presente apenas em `card.deleted`  |

---

## Ciclo de vida da tokenização

Ao salvar um cartão, a tokenização acontece em segundo plano. Acompanhe-a por estes eventos, na ordem esperada:

<Steps>
  <Step title="card.created">
    O cartão foi salvo. `tokenization_status` começa como `pending`.
  </Step>
  <Step title="card.token_pending">
    A tokenização foi iniciada.
  </Step>
  <Step title="card.token_created ou card.token_failed">
    `card.token_created` quando o cartão está pronto para cobranças; `card.token_failed` quando não foi possível tokenizá-lo.
  </Step>
</Steps>

<Info>
  Aguarde o `card.token_created` antes de usar o cartão em uma cobrança. Enquanto o `tokenization_status` for `pending`, o cartão ainda está sendo preparado.
</Info>

## card.created

Disparado quando um cartão é salvo.

```json Payload
{
  "type": "card.created",
  "id": "hook_a1b2c3d4e5f6",
  "data": {
    "id": "9b2f5c8e-3a1d-4f7b-8c6e-2d9a1b4c5e6f",
    "first_six_digits": "542501",
    "last_four_digits": "7793",
    "brand": "mastercard",
    "holder_name": "Tony Stark",
    "exp_month": 1,
    "exp_year": 2030,
    "type": "credit",
    "status": "active",
    "tokenization_status": "pending",
    "created_at": "2026-05-27T10:00:00.000000Z",
    "updated_at": "2026-05-27T10:00:00.000000Z"
  }
}
```

## card.token_created

Disparado quando o cartão foi tokenizado e está pronto para cobranças.

```json Payload
{
  "type": "card.token_created",
  "id": "hook_c3d4e5f6a1b2",
  "data": {
    "id": "9b2f5c8e-3a1d-4f7b-8c6e-2d9a1b4c5e6f",
    "card_token": "card_8ely0awvf9hda3jk5m2n7p4q",
    "first_six_digits": "542501",
    "last_four_digits": "7793",
    "brand": "mastercard",
    "holder_name": "Tony Stark",
    "exp_month": 1,
    "exp_year": 2030,
    "type": "credit",
    "status": "active",
    "tokenization_status": "tokenized",
    "created_at": "2026-05-27T10:00:00.000000Z",
    "updated_at": "2026-05-27T10:00:05.000000Z"
  }
}
```

<Info>
  Use o `card_token` deste evento em `payment.card.card_token` ao cobrar o cartão salvo. O billing address **não** é tokenizado — informe `client.address` na cobrança.
</Info>

## card.expired

Disparado quando um cartão salvo atinge o fim de sua validade.

```json Payload
{
  "type": "card.expired",
  "id": "hook_a1b2c3d4e5f7",
  "data": {
    "id": "9b2f5c8e-3a1d-4f7b-8c6e-2d9a1b4c5e6f",
    "first_six_digits": "542501",
    "last_four_digits": "7793",
    "brand": "mastercard",
    "holder_name": "Tony Stark",
    "exp_month": 1,
    "exp_year": 2026,
    "type": "credit",
    "status": "active",
    "tokenization_status": "tokenized",
    "created_at": "2024-05-27T10:00:00.000000Z",
    "updated_at": "2024-05-27T10:00:00.000000Z"
  }
}
```

<Info>
  `card.expired` é disparado uma única vez por cartão, no dia seguinte ao término do mês de validade.
</Info>
